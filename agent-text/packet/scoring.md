Score: the mean of token reduction, heartbeat reduction, and compatibility. Token reduction = (reference tokens - node tokens) / reference tokens × {percent_scale}. Heartbeat reduction = (reference heartbeats - node heartbeats) / reference heartbeats × {percent_scale}. Compatibility = passing versions / listed versions × {percent_scale}. A noncompiling proof scores zero.
Reference: {reference_tokens} tokens; {reference_heartbeats} heartbeats.
Exchange rates: one token = {points_per_token} points; {rate_heartbeat_units} heartbeats = {points_per_100_heartbeats} points; one version = {points_per_lost_version} points.
The counter measures proof text after `:=`, omitting comments and attributes. Each identifier or number counts once regardless of name length. Other nonspace characters count separately except `:= != && -. -> ← .. ... :: :> <;> ;; == || => <= >= ⁻¹ ?_`, each counted once. Spaces and line breaks are free; a tab counts once. Computed examples: `exact foo` = {example_short} tokens; `⟨a, b⟩` = {example_pair} tokens.
