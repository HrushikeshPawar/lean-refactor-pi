Scoring facts. Proxy = (token_reduction% + heartbeat_reduction% + compatibility%) / 3, where token_reduction% = (reference_tokens - tokens) / reference_tokens * 100, heartbeat_reduction% = (reference_heartbeats - heartbeats) / reference_heartbeats * 100 (heartbeats in `maxHeartbeats` units, measured with `maxHeartbeats 0`) and compatibility% = versions that compile / versions listed * 100; a proof that does not compile scores 0 on all three. Tokens are counted by the harness's pinned counter on the text after the statement's `:=`, with comments and attributes removed: each run of letters, digits, `.`, `_`, `'` is one token whatever its length, every other non-space character is one token (so `⟨a, b⟩` is 5), except the operators `:= != && -. -> ← .. ... :: :> <;> ;; == || => <= >= ⁻¹ ?_`, which count once. Spaces and line breaks are free; a tab counts as a token. `_` can replace any argument or term Lean infers; restating it, such as a lambda, costs tokens.
